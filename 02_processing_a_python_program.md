### 🔹 Steps to Execute a Python Program

1. 📝 **Editor** – Write code in a text editor or IDE (e.g., VS Code, PyCharm)  
   **ایڈیٹر** میں پائتھون کوڈ لکھا جاتا ہے۔

2. ⚙️ **Interpreter** – Python interpreter (like CPython) translates and executes code **line by line**  
   **انٹرپریٹر** کوڈ کو لائن بہ لائن ترجمہ اور عملدرآمد کرتا ہے۔

3. 🖥️ **Execution** – The program runs, output appears on screen  
   **ایگزی کیوشن** کے دوران پروگرام چلتا ہے اور نتیجہ ظاہر ہوتا ہے۔

> ❗ Note: The **CPU ultimately executes** the low-level instructions generated by the interpreter — but **not the Python source code directly**.

# 🧠 **Solving Example Problem using the Full Cycle**

## 🟨 Problem: Find the Perimeter and Area of a Rectangle

---
## 🟨 1. Define the problem

We need to find the perimeter and area of a Rectangle.

We need:
* **Length** of a rectangle
* **Width** of a rectangle


## 🔁 2. **Problem Analysis**

For length and width, we need to:

* manually initialize two variables with the values of length and width,

  OR

* Get length and width from the user


We need to **calculate**:

* **Perimeter**: `2 × (length + width)`
* **Area**: `length × width`

* Display the results as output on screen.
---

## 📐 3. **Algorithm Design**

(Write step-by-step instructions before coding)

**Algorithm:**

1. Start
2. Input the length of the rectangle
3. Input the width of the rectangle
4. Calculate perimeter = 2 × (length + width)
5. Calculate area = length × width
6. Display perimeter and area
7. End

---

## 💻 4. **Coding (Python)**

```python

# Step 1: Input
length = float(input("Enter length of rectangle: "))
width = float(input("Enter width of rectangle: "))

# Step 2: Processing
perimeter = 2 * (length + width)
area = length * width

# Step 3: Output
print("Perimeter of Rectangle =", perimeter)
print("Area of Rectangle =", area)
```

---

## 🧪 5. **Interpretation**

Behind the scenes, here’s what happens:

The interpreter reads each line.
Converts it into tokens (a, =, 3, +, b, etc.).
Builds an Abstract Syntax Tree(which represents the program structure) and then bytecode.


## 🧪 5. **Python Virtual Machine (Executes Bytecode):**

The PVM executes the bytecode line by line and translates it into machine instructions.

## 6. **Loader**

   Machine instructions are loaded into RAM:

## 7. CPU fetches and executes:

The CPU reads instructions from RAM, decodes them, and executes them.

This process is managed by the OS and the Python runtime — you don’t see this happening.

## ✅ 8. **Output (Result on Screen):**

 Finally, the program’s result is shown on the screen.

```
Enter length of rectangle: 10  
Enter width of rectangle: 5
```

## ✅ Summary  

- **Python** is a **high-level**, **interpreted**, and **easy-to-use** language.  
- It uses an **interpreter**, not a compiler like C++.  
- Programming involves: **Understanding problem → Algorithm → Code → Test**  
- Writing an **algorithm is mandatory** for every problem.  
- Flowcharts and pseudocode are optional but helpful in exams.
